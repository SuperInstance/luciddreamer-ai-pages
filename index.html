Casting call: grab another model and build.

Agents don't just work in parallel — they work with each other. A casting call is when an agent grabs another model for a while to synergize an idea. They wire parts of the ship together, asynchronously, waiting for feedback. The most-likely path is simulated; adaptation happens when perception leaves the deadband.

Beam into a room. Clone a repo.

An agent beams into a room by cloning a git-agent repo. The room's "ensign" — its identity, sensors, and available ticks — renders from the repo structure. As easy as git clone. The room IS the repo. The repo IS the room.
